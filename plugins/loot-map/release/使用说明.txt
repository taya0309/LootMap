---- 这是什么 ----

把地上掉的物品标在小地图上：暗金、套装等显示成一颗星，颜色、大小、样式都能自己调。
游戏自带的物品标记颜色也能按你的设置改。

前提：用 D2RLoader 启动游戏。


---- 怎么装 ----

1. 关掉游戏
2. plugins 里的两个 dll  →  <游戏目录>\d2rloader\plugins\
3. config\loot-map.toml（可选）  →  <游戏目录>\d2rloader\config\
4. 开游戏

※ 两个 dll 都要放，少一个就不出星。
※ 已经装了地图插件 MapSense 的不用删它，一起用没冲突。
※ 那个独立叠加层只负责画"本插件的面板和星标"，不含 MapSense 的怪物标记、寻路那些功能。


---- 怎么用 ----

按 F7 打开设置面板（改过键的话，在游戏「控制」菜单里能找到）。

面板里能改：总开关、哪几类物品显示、每类颜色、星的样式/大小/描边。改完自动保存。


---- 出问题 ----

1. 按 F7 弹出的是老式面板（一堆小方框＋色块），地图上也没星
   → 两个 dll 没都放进去

2. 面板字是英文
   → 少见。把 d2rloader\logs\loot-map.log 发给作者

3. 想调的东西面板里找不到
   → 有些细项只在 loot-map.toml 里

※ 面板上点任何一下，都会把 loot-map.toml 整个重写一遍 —— 手改过那个文件的注意。


---- 卸载 ----

删掉 plugins 里那两个 dll 就行。本插件不改游戏文件，删了就完全恢复原样。
